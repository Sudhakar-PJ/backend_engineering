# Error Journal

> Every bug you hit, every `REVISIT` marker, every "aha" moment that cost you time. This is the highest-leverage file in the repo — read it before starting a new tier.

---

## Format

| # | Date | Tier / Topic | Type | Symptom | Root Cause | Takeaway |
|---|---|---|---|---|---|---|

**Type** values:
- `BUG` — a bug in your code
- `ENV` — environment/config issue (skip unless it recurs)
- `GAP` — a genuine learning gap
- `REVISIT` — a topic you deferred (per Stuck Protocol)
